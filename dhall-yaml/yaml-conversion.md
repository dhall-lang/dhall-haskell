# Dhall and YAML conversion

This document is the contract for `dhall-to-yaml-ng` and `yaml-to-dhall` in this package. It is not a dhall-lang standard. The language standardizes Dhall and JSON. `Prelude/JSON/renderYAML` is a smaller pure-Dhall renderer and is not this contract.

`dhall-json`'s `dhall-to-yaml` executable is a different renderer (`aeson-yaml`). Its output is not a rule for this package. The golden `tasty/data/normal-aeson` is that other renderer: it leaves the YAML 1.1 bool word `y` unquoted (`yes: y`). This package quotes it. The yamlet case of that golden is an expected failure.

Each normative rule names the test that locks it. Tests live in `tasty/Main.hs` and `tasty/data/`.

## Encode

`dhallToYaml` evaluates the Dhall expression with `UseYAMLEncoding`, producing a JSON value, then renders that value as YAML.

`UseYAMLEncoding` rewrites `Infinity`, `-Infinity`, and `NaN` to the strings `inf`, `-inf`, and `nan` before rendering. Test: `./tasty/data/special-doubles` (fields `positive`, `negative`, and `notANumber`).

Those strings are then rendered like any other string. `inf` and `nan` are plain. `-inf` is double-quoted because `-` is not a plain character in the core schema encoder. The same test locks that presentation.

### Scalars

The renderer walks the JSON value. For a string, in this order:

1. If the string contains a newline, it is a literal block scalar (`|`). This wins over `--quoted`. Tests: `./tasty/data/normal` (field `text`) and `./tasty/data/quoted` (field `text`).
2. Otherwise the string is single-quoted when any of these hold:
   - `--quoted` is set. Test: `./tasty/data/quoted`. That flag quotes string keys and string values. It does not quote bools or numbers.
   - Every character is a digit, `.`, `e`, or `-`. The empty string matches. Test: `./tasty/data/quoting-edges` (`01`, `1e2`, `-3`, `.`, and `""`) and `./tasty/data/normal` (`2000-01-01`).
   - The string is a YAML 1.1 bool word, case-insensitive, and its length is at most 5: `y`, `yes`, `n`, `no`, `true`, `false`, `on`, `off`. Tests: `./tasty/data/boolean-quotes`, `./tasty/data/normal` (`true` and `y`), and `./tasty/data/quoting-edges` (`YES`, `On`, `false`). A longer word stays plain. Test: `./tasty/data/quoting-edges` (`yesterday`).
3. Otherwise the YAML 1.2 core schema encoder chooses the style. A string of plain characters that the core schema reads as a string, with no leading or trailing space, is plain. Test: `./tasty/data/normal` (`hello world`). Anything else is double-quoted. Tests: `./tasty/data/special` (`*`) and `./tasty/data/plain-indicators` (`a: b` and `a #b`).

Bools are the plain scalars `true` and `false`. Test: `./tasty/data/normal`.

Null is the plain scalar `null`. Test: `./tasty/data/null`.

A number that is an integer renders as an integer, including a Dhall `Double` whose value is integral (`1.0` renders as `1`). A non-integer renders in decimal. A negative integer keeps its sign. Test: `./tasty/data/numbers`.

### Collections

Object keys are sorted by their text, because the JSON object is a sorted map. Test: `./tasty/data/key-order`. The Dhall record is written `z`, `m`, `a` and the YAML keys come out `a`, `m`, `z`.

An empty array is `[]`. Test: `./tasty/data/emptyList`. An empty object is `{}`. Test: `./tasty/data/emptyMap`.

A nested array is a block sequence whose `-` items sit at the column of the key. A nested object is a block mapping indented two spaces. Test: `./tasty/data/nested`. The exact indentation is incidental presentation: a later renderer may change the spaces only by updating this paragraph and that golden together.

### Documents, headers, and comments

`--documents` prints `---\n` before every document, including the first. A one-element list and a value that is not a list each become one document. Tests: `./tasty/data/single-document` and `./tasty/data/single-document-bare`. A list of two numbers becomes two documents, with a blank line between them because each document already ends in a newline. Test: `./tasty/data/two-documents`.

`--preserve-header` copies the Dhall comment header in front of the YAML. The header is not YAML structure. Test: `./tasty/data/preserve-header`.

`--generated-comment` prepends `# Code generated by dhall-to-yaml.  DO NOT EDIT.` and a newline. That line is not YAML structure. Test: `./tasty/data/generated-comment`.

## Decode

`yaml-to-dhall` parses one YAML 1.2 document with the core schema into a JSON value, then uses the existing JSON-to-Dhall conversion. Tags are ignored. Anchors are expanded by the parser before that conversion. A realistic mapping is `./tasty/data/mergify`; the scalar rules below are not defined by that fixture.

`true`, `True`, `TRUE`, `false`, `False`, and `FALSE` are `Bool`. Test: `./tasty/data/decode-bools`.

`y`, `yes`, `n`, `no`, `on`, `off`, and `YES` are `Text`. YAML 1.1 bool words are not bools. Test: `./tasty/data/decode-bool-words`. A quoted `'true'` is `Text`, not `Bool`. Test: `./tasty/data/decode-quoted-true`.

`null` with no schema is `None <>`. Test: `./tasty/data/decode-null`.

An integer that is at least zero is `Natural`. A negative integer is `Integer`. A non-integer number is `Double`. Test: `./tasty/data/decode-numbers`.

An empty array is `[] : List <>`. Test: `./tasty/data/decode-empty-list`. An empty mapping is `{=}`. Test: `./tasty/data/decode-empty-map`. A nested sequence and mapping decode as a Dhall list and record. A nested record pretty-prints with dot syntax (`outer.inner`). Test: `./tasty/data/decode-nested`.

A tag outside the core schema leaves the scalar unresolved. `!secret 123` is rejected, and the error contains `unresolved YAML scalar encountered`. Test: `decode-tag`.

The plain scalar `inf` is the string `"inf"`, not a double. `Infinity` was rewritten to that string on the way out, and this is how it reads back. Test: `./tasty/data/decode-plain-inf`.

`.inf`, `-.inf`, and `.nan` are core-schema floats. They become a JSON number by converting the `Double` with `realToFrac`, then a Dhall number. `.inf` is the `Natural` in `./tasty/data/decode-dot-inf.dhall` (the greatest finite `Double`, read back as an integer). `-.inf` is that magnitude as an `Integer`. Test: `./tasty/data/decode-dot-neg-inf`. `.nan` is the `Natural` in `./tasty/data/decode-dot-nan.dhall`. The sign bit of the platform `NaN` is discarded, so that `Natural` is the same on every platform. Test: `./tasty/data/decode-dot-nan`.

A mapping with two equal keys is an error. The message contains `duplicate key`. Test: `decode-duplicate-key`.

A stream with a second document is rejected. The error contains `Multiple documents encountered in YAML stream`. Test: `decode-second-document`.

A key that the core schema does not resolve to a string is rejected. The error contains `non-String key encountered in mapping`. Test: `decode-non-string-key`. The input `1: a` uses an integer key.

## Round trip

YAML produced for a record of a natural, a string, and a bool decodes back to that same Dhall value. The re-encoded YAML does not have to match a golden byte for byte. Test: `./tasty/data/roundtrip`.
